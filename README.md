# Nyarch Media Box

这是一个由 [Debian 小药盒](https://github.com/moesoha/debian-media-box) 和 [Arch 小药盒](https://github.com/Isoheptane/arch-media-box) 启发的 Nyarch Linux 盒装安装介质的平面设计。

This is a graphic design for Nyarch Linux boxed installation media, inspired by the [Debian Media Box](https://github.com/moesoha/debian-media-box) and the [Arch Media Box](https://github.com/Isoheptane/arch-media-box).

---

一切的开始都是那个 Debian 盒装安装介质 的meme , 因为过分类似某品牌的**雌二醇药物**外包装从而诞生。那这个药物作为 femboy 最喜欢的药物之一（特指**非正常**的那种），我们给面向**御宅族**或者Femboy的发行版Nyarch做一个盒子似乎也没有什么问题吧喵(

It all started with the Debian boxed installation media meme, which was born because it closely resembled the packaging of a certain brand of estradiol medication. Since that medication is one of the favourites among femboys (especially the "non‑normal" kind), it seems perfectly fine for us to make a box for Nyarch – a distribution aimed at **otaku** or femboys – right? Nya~ 😸

## 使用及修改 / Usage and Modification

### 对中文用户来说

下载 `box_sourse.zh.pdf` 文件后打印即可。

对于想要编辑或修改的用户，你可以下载 `box_sourse.zh.svg` 进行修改。需要注意的是：你需要自行准备所需的图片以及字体文件。

本项目使用字体有：

```
- Noto Sans
- Noto Sans CJK SC 
- Montserrat
- Inconsolata
- DejaVu Sans
```

### For English Users

Download `box_sourse.en.pdf` and print it.

If you wish to edit or modify the design, download `box_sourse.en.svg`. Please note that you will need to supply the required images and font files yourself.

Fonts used are the same as listed above (they support Latin scripts as well).
